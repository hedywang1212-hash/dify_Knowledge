在某些情况下需要在Servicenow环境中取得当前url来获取url中的信息时

在客户端可以用

var href = location.search;

在服务端可以用

var href =gs.action.getGlideURI();

在UI action端

var href =action.getGlideURI();



然后再通过调用此方法可以获取url中的各个部分的值

 var URLParams = {};
        var params = href.substr(1).split('&');
        for (i = 0; i < params.length; i++) {
            var aParam = params[i].split('=');
            URLParams[aParam[0]] = aParam[1];

        }
例：URLParams[sys_id]
